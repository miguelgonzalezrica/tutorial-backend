# Ludoteca Tan

Este repositorio contiene el codigo backend en Spring Boot de la aplicación de gestión de juegos de la ludoteca Tan. Este código forma parte de mi formación como estudiante en prácticas en Capgemini. 

## Funcionalidades

Se han implementado operaciones CRUD para las distintas entidades mediante endpoints REST. Las principales entidades son:
- Juegos
- Autores
- Categorías
- Clientes
- Préstamos

## Base de datos

Mediante un sencillo script .sql y el uso de Hibernate, e ha construido y gestionado la base de datos de la aplicación.
